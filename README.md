HUNGR.AI
A tiny static website inspired by the idea of giving an AI a "digital snack" when its previous answer is inaccurate, overly agreeable, vague, or otherwise off.
What it does
The site has one main action: Copy Digital HUNGR. Clicking it copies a compact reset prompt. The user pastes that prompt into the same AI conversation and sends it, prompting the model to reconsider its previous response from scratch.
GitHub Pages
Upload these four files to the root of your repository:
`index.html`
`style.css`
`app.js`
`README.md`
Then open Settings → Pages, choose Deploy from a branch, select main and /(root), then save.
No build step, API key, package manager, or backend is required.
